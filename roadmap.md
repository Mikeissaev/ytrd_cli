# Дорожная карта улучшений YTRD

Этот документ описывает предложения по улучшению взаимодействия с пользователем (UX) и добавлению новой функциональности.

## 1. Улучшения User Experience (UX)

### 1.1. Интерактивность и Интерфейс
*   **Rich UI:** Использовать `rich` для таблиц и прогресс-баров, но **опционально**.
*   **Интерактивные меню:** Использовать `questionary` или `inquirer` для навигации стрелками.
    *   **Важно:** Обязательно предусмотреть fallback-режим (обычный ввод) для случаев, когда терминал не поддерживает интерактивность (например, некоторые кейсы в Termux) или при работе в неинтерактивном режиме (`--no-input`).

### 1.2. Управление конфигурацией
*   **Файл конфигурации:** Поддержка `~/.config/ytrd/config.toml` (папка загрузки, качество, режим озвучки, cookies).

### 1.3. Обратная связь
*   **Детальный прогресс:** Показывать статус тяжелых операций merge.
*   **Уведомления:** Опциональные системные уведомления по завершении.

## 2. Новые функции (Features)

### 2.1. Пакетная загрузка (Batch Mode)
*   **Чтение из файла:** Флаг `-f urls.txt`.
*   **Плейлисты:** Поддержка плейлистов YouTube (`--playlist-items`). Реализовать через прокидывание опций в `yt-dlp`.

### 2.2. Расширенная работа с метаданными
*   **Встраивание:** Обложки, теги, главы (Chapters) в итоговый файл.

### 2.3. Улучшенная поддержка субтитров
*   **Embed Subtitles:** Встраивание субтитров (soft subs) вместо внешних файлов.
*   **Авто-перевод:** Использовать автоперевод YouTube, если нет нативных русских субтитров.

### 2.4. Smart History
*   **История:** Локальный лог (SQLite/JSON) для предотвращения повторных загрузок.

### 2.5. Выбор языка (VOT)
*   Экспериментальная поддержка других языков перевода, если API позволяет.

## 3. Технические улучшения (под капотом)
*   **Self-Update:** Опциональная команда для самообновления.
*   **Asyncio:** **Отложено.** Внедрять только при появлении реальной потребности в конкурентном выполнении множества задач, так как основные операции (`yt-dlp`, `ffmpeg`) все равно блокирующие/синхронные. Текущий выигрыш не оправдает усложнения кода.
