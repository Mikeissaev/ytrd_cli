# Changelog

Все заметки о релизах проекта ytrd.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru-RU/1.0.0/),
и проект придерживается [Semantic Versioning](https://semver.org/lang/ru-RU/).

## [0.4.6] - 2025-12-31

### Added
- Тесты для модуля `platform.py` (22 теста)
- Секция "Установка на Android (Termux)" в README.md
- Примеры использования в README.md

### Changed
- Обновлен README.md с улучшенной структурой и таблицами опций
- Модуль `platform.py` теперь использует `os.path` вместо методов `Path` для последовательности
- Модуль `config.py` - добавлены константы для минимального размера файла

### Refactoring
- Убраны циклические зависимости между модулями
- Добавлена иерархия исключений (`errors.py`)
- Добавлены type hints во все публичные функции

## [0.4.5] - 2025-12-30

### Added
- Модуль `platform.py` для кроссплатформенной поддержки
- Модуль `errors.py` с иерархией исключений проекта
- Поддержка переменных окружения для `VOT_HMAC_KEY`

### Changed
- Убрана циклическая зависимость между `vot.py` и `downloader.py`
- `vot.get_translation_audio()` теперь возвращает кортеж `(success, url)`
- Все `sys.exit()` вызовы перемещены в `main.py:entry_point()`

### Fixed
- Исправлено дублирование кода в `cli.py`
- Улучшена валидация скачанных файлов

## [0.4.0] - 2025-12-29

### Added
- Поддержка Android Termux как основной платформы
- Поддержка cookies для скачивания субтитров
- Режим "Живой голос" (Live Voice)

### Changed
- Рефакторинг структуры проекта
- Улучшена обработка ошибок

## [0.3.x] - 2024

### Added
- Режим смешивания аудио (Mix)
- Режим двух дорожек (Dual)
- Режим "Только аудио"
- Поддержка субтитров
- История скачиваний

## [0.1.0] - 2024

### Added
- Первый релиз
- Базовое скачивание видео с YouTube
- Автоматическое наложение перевода
